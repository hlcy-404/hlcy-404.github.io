# 设计规范 · Field Notes

## 风格来源与转译

参考用户提供的 Feather Atlas 提示词：暖纸色、鼠尾草绿、衬线字、左导航/中央展示/右详情三栏、标本编号、细线图标、昼夜模式。

本项目采用“个人探索手册”的编辑式阅读体验。中央曲面是原创矢量概念插图，表达观察、连接与构建，不是论文图表。未使用参考中的鸟类图片、GLB 模型、Three.js 或外部字体；无大型媒体下载成本。

对博客的适配：页面自然滚动；文章入口可达；移动端按主内容、方向面板、记录顺序排列。避免固定 100vh 与底部内滚动卡片压缩阅读空间。

## 布局与组件

- 桌面侧栏 212px，主内容适度限宽；方向面板 270px。
- 850px 以下首页转顶部导航；640px 以下主区单列。内页仍用 Chirpy 自带移动菜单，避免两套抽屉同时运行。
- 方向切换使用标准 tablist/tab/tabpanel，支持方向键及 Home/End。
- 搜索有文本标签与结果播报；筛选按钮用 aria-pressed；装饰图标对读屏隐藏。
- 文字链接和按钮要有明确目的，不出现无操作效果的通知、账号、点赞等装饰按钮。
- 无文章时显示空态，不填假作品；无匹配时可清除筛选。
- 少量 transform 动效可关闭；遵循 prefers-reduced-motion；保留页面缩放与可见焦点。
- 首页简介使用主栏完整宽度；1280px 及以上桌面保持一行，较窄屏幕自然换行。首页不再放置“阅读记录”和“查看归档”两处快捷按钮。
- 友链页采用细线分隔的人物条目：本地照片（缺少时用字母标识）、姓名、关系、简介、方向和主页链接。宽屏两列，640px 以下单列；照片按原比例展示，长简介分段，配色读取既有昼夜变量。
- 友链桌面左侧为不超过 180px 的照片及姓名，右侧为完整介绍；手机照片不超过 120px，与姓名并排，正文置于下方。照片容器有局部宽度兜底，不依赖外部样式才能控制尺寸。

## 修改原则

本地写作“备份与空间”使用固定标题栏和可滚动内容区，打开时锁定背景滚动。680px 以下采用单列、两列空间统计卡片，列表及恢复/清理摘要不再单独滚动；长标题、路径按可用宽度换行。主要按钮与下载链接点击高度至少 44px，确认/取消纵向排列。关闭按钮始终可见，恢复/清理核对后焦点移到摘要，Escape 关闭返回入口。已验收 375×812、375×667 与桌面 1280×900；不等同于真机验收。

先改变量和共享组件，再改局部选择器。保留长标题、长标签和空内容的容纳空间。每次改变字体或布局后检查桌面、375px 和夜间模式，不以单张首页截图替代文章阅读验证。
