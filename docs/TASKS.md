## 后续优先级

| 优先级 | 功能/内容 | 价值与适用场景 | 成本与边界 | 验收条件 |
| --- | --- | --- | --- | --- |
| P0 | 发布 3 篇内容入口 | 让访客有具体内容可读：方向介绍、代表工程、研究记录 | 需要真实材料，视觉无法代替内容 | 标题、摘要、证据、复现/后续入口完整 |
| P0 | 完善公开简介 | 明确身份、合作方向与联系方式 | 由用户决定可公开范围 | 不含模板信息，所有资料可核对 |
| P1 | 项目展示页 | 连接博客与可运行作品，方便同行判断实际能力 | 建议积累至少 2 个可公开项目再建 collection | 每项有问题、角色、技术、证据、链接和当前状态 |
| P1 | 系列文章导航 | 对 Agent/评测/部署等连续主题提供阅读顺序 | 先有 3 篇以上同主题内容 | 前后篇、目录、系列入口与原 URL 兼容 |
| P1 | 文章引用与更新记录 | 增强科研内容可核查性，降低过时结论误用 | DOI/BibTeX、环境信息需要作者维护 | 参考资料可追溯，更新日期与实质变化一致 |
| P1 | 每篇分享图与元数据 | 改善外部分享预览与可发现性 | 需用户确认头像/封面使用范围 | og:title/description/image 和 canonical 浏览器检查通过 |
| P1 | 长文阅读体验回归 | 公式、图表、目录、代码复制、图片放大 | 复用主题；第三方 CDN 访问质量需实测 | 真实长文在手机和桌面可读、可复制 |
| P2 | 全文搜索/分页 | 文章规模增长后的查找效率 | 约 100 篇后测量；优先静态索引，注意中文分词 | 真实检索样例、结果相关性、体积/延迟达标 |
| P2 | 评论/反馈（如 giscus） | 同行讨论与错误反馈 | GitHub 登录门槛、维护和审核成本；需用户授权配置 | 实际发帖/回复测试，隐私提示清楚 |
| P2 | /now 与短札记 | 展现持续创作而非简历式静态页面 | 需要稳定更新习惯；不展示虚构活跃度 | 更新有日期，过期状态可辨识 |
| P2 | 轻量访问统计 | 判断读者关注内容 | 当前不启用；先确定隐私与数据需求 | 可说明收集字段、保留期与决策用途 |
| P3 | 站内 AI 问答 | 内容较多且有可靠引用时辅助查找 | 成本、幻觉、限流、隐私、密钥保护都增加维护负担 | 来源引用、拒答、滥用防护、成本边界可测试 |

推荐次序：真实内容与公开简介 → 项目与系列 → 可核查的阅读体验 → 根据读者反馈选择互动能力。当前不建议先做账号系统、在线编辑后台或重型 AI 助手。
