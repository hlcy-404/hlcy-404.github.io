## 背景与目标

这是 hlcy-404 的个人博客，工作方向包括人工智能、计算技术、大模型、Agent 与科研工程。原项目具备 Jekyll + Chirpy 与 GitHub Pages 的发布基础，但没有正式文章，展示仍含模板资料。

网站需要让首次访问者快速理解作者的关注方向，让回访者找到文章，让作者能持续积累研究与工程记录。个人经历、论文、项目和联系方式必须有用户提供的依据。

## 主要访问路径

| 读者目的 | 路径 | 成功条件 |
| --- | --- | --- |
| 认识作者 | 首页 → 关于我 → GitHub | 能看懂关注方向，无虚构履历 |
| 找一篇文章 | 首页搜索/分类筛选 → 文章 | 标题、摘要、标签可匹配；空结果可恢复 |
| 浏览内容 | 全部文章 / 分类 / 标签 → 文章 | 各入口可达，原文章 URL 保留 |
| 持续关注 | RSS | feed.xml 可访问，含实际发布文章 |
| 作者更新 | Markdown → 本地预览 → 手动同步 | 先验证再发布，保存不自动推送 |

## 首版范围

- 三栏首页：左侧导航、中间导语与视觉、右侧探索方向；移动端顺序流式布局。
- 研究、构建、记录方向切换，键盘方向键、Home、End 操作。
- 日间/夜间模式，同源持久化，存储不可用时允许本次切换。
- 自动读取文章，置顶优先，分类筛选，标题/摘要/标签搜索，空态与无结果态。
- 中文站点信息、现有头像、真实 GitHub 身份和用户已提供的工作方向。
- 继续使用 Chirpy 的文章、分类、标签、归档、TOC、代码块和现有发布体系。
- 文档化的需求、架构、设计、任务、内容写作和验证流程。

## 范围外

本轮不新增账号系统、后台 CMS、数据库、在线 AI 聊天、访问统计、评论服务、邮件订阅或自动发布。不虚构文章、项目、成果、单位、学历、邮箱。首页视觉不构成研究成果或真实数据图示。

## 验收条件

1. 生产模式构建成功，站内链接检查通过，开发文档与 `.local` 不进入产物。
2. 首页、关于、归档、分类、标签能正常打开；测试文章能进入阅读页。
3. 搜索、分类、置顶、无结果恢复、方向切换与主题切换按预期工作。
4. 375px 移动布局和桌面布局无横向溢出，键盘可访问主要功能；减少动态效果设置生效。
5. 测试文章只存在于 `.local` 中的独立测试站点；正式 `_posts` 不增加示例作品。
6. 本地文件、构建、浏览器、Git 提交、远程部署分别记录状态。
