## 背景与目标

这是 hlcy-404 的个人博客，工作方向包括人工智能、计算技术、大模型、Agent 与科研工程。原项目具备 Jekyll + Chirpy 与 GitHub Pages 的发布基础，但没有正式文章，展示仍含模板资料。

网站需要让首次访问者快速理解作者的关注方向，让回访者找到文章，让作者能持续积累研究与工程记录。个人经历、论文、项目和联系方式必须有用户提供的依据。

## 主要访问路径

| 读者目的 | 路径 | 成功条件 |
| --- | --- | --- |
| 认识作者 | 首页 → 关于我 → GitHub | 能看懂关注方向，无虚构履历 |
| 找一篇文章 | 首页搜索/分类筛选 → 文章 | 标题、摘要、标签可匹配；空结果可恢复 |
| 浏览内容 | 全部文章 / 分类 / 标签 → 文章 | 各入口可达，原文章 URL 保留 |
| 持续关注 | RSS | feed.xml 可访问，含实际发布文章 |
| 作者更新 | Markdown → 本地预览 → 手动同步 | 先验证再发布，保存不自动推送 |
